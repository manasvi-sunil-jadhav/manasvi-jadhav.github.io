Retail Sales SQL Analysis

SQL · BUSINESS ANALYSIS · SQLITE

This project explores retail sales data using SQL to uncover business insights related to sales performance, customer behaviour, product trends, and regional performance. The analysis is performed using the Sample Superstore dataset in SQLite and is organised into six structured SQL scripts, progressing from basic exploration to intermediate SQL techniques.

Project Overview

The project uses SQL to analyse retail sales data and examine different aspects of business performance, including sales, customers, products, and geographical patterns.

The analysis is structured across six SQL scripts, beginning with data exploration and progressing towards more advanced SQL techniques.

Objectives

  • Explore and understand the dataset.
  • Analyze overall sales performance.
  • Identify high-value customers.
  • Evaluate product performance.
  • Compare regional sales trends.
  • Demonstrate intermediate SQL concepts through practical business analysis.

Dataset

The analysis uses the Sample Superstore dataset, containing information related to:

Orders Order-related information
Customers Customer information
Products Product-level information
Sales & Profit Sales and profitability measures
Quantity & Discounts Transaction-level measures
Geographic Locations Regional and location information

The dataset is included in the project repository.

SQL Analysis

The analysis is organised into six structured SQL scripts, each focusing on a different aspect of the retail dataset.

01 · Data Exploration Understanding dataset structure, inspecting records, exploring key columns, and performing initial data validation.
02 · Sales Analysis Total sales, sales by category and segment, sales trends, and profit analysis.
03 · Customer Analysis Top customers, customer contribution, segment analysis, and purchasing behaviour.
04 · Product Analysis Best-selling products, product profitability, category comparison, and product performance.
05 · Geographical Analysis Sales by state and city, regional comparison, and geographical business insights.
06 · Advanced SQL CASE statements, CTEs, HAVING, ROW_NUMBER(), RANK(), NTILE(), and window functions.

SQL Concepts Used

SELECT WHERE GROUP BY ORDER BY HAVING Aggregate Functions CASE CTE ROW_NUMBER() RANK() NTILE() Window Functions

Business Questions Answered

  • Which categories generate the highest sales?
  • Which customers contribute the most revenue?
  • Which products perform best?
  • Which regions are the most profitable?
  • How are customers distributed across sales levels?
  • Which products receive the highest discounts?
